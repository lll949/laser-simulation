# laser-simulation
Code for laser simulation in the paper
domain and space: create spatial and spectral coordinates.
plot_complex_field: generates an image where brightness encodes intensity and color encodes phase. 
doub: simulation of a laser cavity containing two gain media. 
eighty: simulation with a single 80 mm long gain medium. 
forty: simulation with a single 40 mm long gain medium. LG: generates Laguerre‑Gaussian (LG) modes of different orders.

The MATLAB version used for this code is R2021a.
